GGUF Loader

Private Local AI with a Built-In Agent

GGUF Loader is a universal model loader — run GGUF models fully offline and pick the one that fits your PC's resources. It ships with a built-in plan-driven agent that reads, creates, and organizes files in any workspace you choose. No cloud. No subscriptions. Your data never leaves your machine.

🧪 Note: the new v2.3.0 testing release is temporarily optimized for one model (Gemma 4 12B Instruct) so its agentic work runs well — universal model support returns in the next release.

❓ Frequently Asked Questions

🧠 What is GGUF Loader?

GGUF Loader is a free, open-source desktop app that runs Google Gemma 4 12B Instruct fully locally and includes a plan-driven agent that can read, create, and organize files in a workspace you choose. No Python, no cloud, no subscriptions.

📦 What is GGUF?

GGUF is an optimized model file format used by llama.cpp. It's designed for efficient local deployment of large language models on consumer hardware.

💻 Do I need Python or command line expertise?

No. Download the EXE and double-click — everything is bundled. Prefer Python? pip install ggufloader and run ggufloader. Both paths get you the same app.

🌐 Does it work completely offline?

Yes. Once the model is on disk, everything runs entirely offline — chat, agent, and file tools. Your prompts and files never leave your machine.

🧩 What models are supported?

This testing release is pinned to Gemma 4 12B Instruct Q4_K_M — it's auto-downloaded on first launch. Other GGUF files are rejected with a clear message. The next release adds a Universal Model Loader that accepts any GGUF model matched to your hardware.

🤖 What can the agent actually do?

It plans multi-step tasks and runs sandboxed tools in a workspace folder you grant: list/read/write/edit/move files, search, shell commands, Python, and git. Sensitive actions pause for your Allow/Deny approval, and every step streams inline in the chat.

⚡ Can I use my GPU?

Yes — open Settings → Hardware and click Install GPU Support. The app installs the CUDA (Windows/Linux) or Metal (macOS) build with live status. CPU-only builds work on any machine.

🪟 What platforms are supported?

Windows 10/11, Linux, and macOS (including Apple Silicon). Prebuilt executables are published on the GitHub Releases page.

🧪 Is this release stable?

v2.3.0 is a testing release — the single-model agent architecture is new and we're validating it before expanding model support. Expect rough edges and please report issues.

🤝 Is the source code available?

Yes, GGUF Loader is fully open source under the MIT license. View the complete source code on GitHub.

We believe everyone should have the right to powerful AI tools — locally, securely, and without needing to code. GGUF Loader brings this to life: no Python, no internet, just click-and-run intelligence on your own machine.
